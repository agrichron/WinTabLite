# WinTab Lite 使用说明

## 唤出方式

| 方式 | 说明 |
|---|---|
| `Alt + Tab` | 接管系统任务切换器（默认开启，可关） |
| `Alt + \``（反引号） | 主热键，按一次开、再按一次关 |
| 鼠标撞屏幕左边缘 | 停顿约 0.3 秒滑出，适合纯鼠标操作 |
| 托盘图标 | 单击唤出，右键菜单 |

面板永远贴在**鼠标所在那块屏幕**的左边缘。

## 面板内操作

| 操作 | 效果 |
|---|---|
| 左键点缩略图 | 切到该窗口，面板收起 |
| 鼠标移到缩略图上 → 点右上角 ✕ | 关闭该窗口（发 `WM_CLOSE`，程序自己的保存提示会正常弹出），面板不收起，可连续关 |
| 滚轮 | 上下滚动 |
| 鼠标移出面板 | 约 0.35 秒后收起（前提：鼠标先进入过面板） |
| 再按 `Alt + \`` | 收起 |

### 驻留规则

唤出后**不会自己消失**：

- 唤出那一刻鼠标通常不在面板上，此时**不计入"移出"**，面板一直驻留。
- 鼠标没进过面板时，只要在屏幕任何地方点一下，面板立刻收起（全局鼠标钩子只监听点击位置，不拦截事件，被点的窗口照常收到点击）。
- 只有鼠标**进过面板、之后又移出去**，才会在 0.35 秒后自动收起。
- 面板收起后 1.2 秒内，左边缘不会立刻把它重新弹出来（防抖）。

## 排序规则

默认 `sort = app_group`：

1. **组**按进程 exe 文件名（ASCII）升序——`Code.exe < explorer.exe < msedge.exe < Obsidian.exe < WindowsTerminal.exe < Xshell.exe`。
2. **组内**按窗口标题字母序，中文走系统 locale 的拼音规则（`阿里云盘 < 钉钉 < 飞书 < 腾讯会议 < 微信`）。
3. 组间不画分界线，靠右下角的应用图标辨认分组。

> 为什么用 exe 名而不是显示名排组：中文应用名按 Unicode 码位排出来完全不可预测，用户无法形成位置记忆。

改成 `sort = zorder` 则退回纯窗口层级（最近用过的大致在前）。

## 尺寸与多屏适配

程序是 per-monitor DPI aware，但**不做 Qt 的逻辑像素缩放**，所有尺寸都是物理像素。

`scale = auto` 时由**物理工作区反推倍数**，DPI 自然被算进去：

```
scale = min(工作区宽 × 0.42 / 458,  工作区高 × 0.90 / 857)   # 钳制在 0.9 ~ 2.6
```

含义是"保证 2 列 × 5 行放得下，且不超工作区 42% 宽 / 90% 高"。实测：

| 分辨率 | scale | 单元格 | 面板宽 |
|---|---|---|---|
| 1366×728 | 0.90 | 187×105 | 411（30%） |
| 1920×1040 | 1.09 | 227×128 | 499（26%） |
| 2560×1400 | 1.47 | 306×172 | 675（26%） |
| 3840×2114 | 2.22 | 462×260 | 1018（27%） |

三条兜底：

- 宽度不够时**先减列**（3 列放不下就退回 2 列），再不够就缩 `scale`。
- 高度不够时改为**滚动**。
- 最终位置钳制在目标屏工作区内，副屏在主屏左侧（坐标为负）也不会露出屏幕外。

### 跨屏 DPI

窗口从 150% 屏移到 100% 屏时，Windows 会发 `WM_DPICHANGED` 想把窗口按 2/3 缩放（实测 505×945 → 337×630，导致右列被切）。程序在 `nativeEvent` 里**拒绝这条消息**并用 `SetWindowPos` 强制维持自己算的尺寸；角标覆盖窗同样处理。

## Alt+Tab 接管

`intercept_alt_tab = true` 时用**低级键盘钩子**（`WH_KEYBOARD_LL`）拦截 `Alt+Tab` / `Alt+Shift+Tab`：

- 系统原本的任务切换器不再弹出，改为打开本面板。
- 连按 Tab 不会反复开合（面板已可见时忽略）——本工具是鼠标操作，按住 Alt 连按没有意义。
- 顺带吞掉紧随的 **Alt 抬起**，避免触发窗口菜单栏。
- 关闭方式不变：点缩略图、点面板外、或按 `Alt + \``。
- 改回 `false` 并重启即恢复系统 Alt+Tab。

> Windows 把 `Alt+Tab` 列为系统保留组合，`RegisterHotKey` 注册会直接失败，只能用键盘钩子。

## 开机自启

托盘右键有「开机自启」勾选项，勾选即写入、取消即删除，打开菜单时自动同步状态。

写入位置（当前用户，无需管理员）：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\WinTabLite.lnk
```

命令行等价操作：

```bat
python autostart.py            # 查看状态
python autostart.py --install  # 设置
python autostart.py --remove   # 取消
```

打包成 exe 后，快捷方式目标会自动指向 exe 本身；源码方式则指向 `pythonw.exe + wintab_lite.py`。

## 打包

```bat
build.cmd
```

- 产物 `dist\WinTabLite.exe`，onefile，约 60MB，启动时会有引导父进程 + 应用子进程两个进程，属正常。
- `config.ini` 必须与 exe 同目录：打包后 `__file__` 指向临时解包目录，代码里已改为用 `sys.executable` 所在目录读配置。
- 图标由 `tools/make_icon.py` 生成到 `assets/`。

## 调试

```bat
python wintab_lite.py --shot out.png   # 不开常驻，直接把面板画出来存图
python wintab_lite.py --show           # 直接显示面板，不进托盘
python tests/selftest.py               # 自检：枚举/标题/缩略图/焦点
```

`tests/` 下是**手工验证脚本**，会用真实鼠标点击、真实窗口，不是单元测试：

| 脚本 | 验证内容 |
|---|---|
| `test_resident.py` | 唤出后鼠标不在面板上也不会自动消失 |
| `test_click.py` | 点面板内不收起、点面板外立刻收起 |
| `test_close.py` | 关闭按钮的点击路由，以及 `WM_CLOSE` 真的能关窗口 |
| `test_dpi.py` | 跨屏移动后窗口尺寸未被 `WM_DPICHANGED` 缩放 |
| `test_overlay.py` | 验证 DWM 缩略图会盖住同窗口内的绘制（原生子窗口会被盖掉） |
| `test_alttab.py` | `Alt+Tab` 被钩子吞掉并触发回调 |

## 已知限制

- 不支持键盘操作：方向键、Esc 都不可用，这是"不抢焦点"的必然代价。
- 不收录其他虚拟桌面上的窗口：DWM 缩略图机制取不到，硬列出来只能是黑块。
- 少数挂起的 UWP 窗口可能显示为空白格（标题还在）。
- 远程桌面会话下 DWM 行为可能异常，缩略图可能不刷新。
- 关窗口时若弹出保存确认框，可能被置顶的面板挡住——点一下面板外关掉面板即可看到。
